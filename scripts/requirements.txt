# Ingestion is now handled by the published bsky-saves package.
# It pulls in httpx + trafilatura transitively.
#
# v0.2 introduced an ingestion/transformation split: bsky-saves now
# downloads images into a flat cache and records the URL→path mapping
# as `local_images` on each inventory entry, while the Jekyll-aware
# Markdown rewriter lives here in `scripts/localize_story_images.py`.
# The `fetch images` workflow chains the two together.
#
# v0.2.2 completes the no-write-on-no-change pattern across every
# ingestion subcommand (`fetch`, `enrich`, `hydrate articles`,
# `hydrate threads`, `hydrate images`). With this pin, every
# fetched_at-revert hack in our workflow scripts can come out — a
# clean inventory diff is finally a real no-op signal.
#
# Upper bound: `<1.0`. The cap-at-current-minor pattern (originally
# `<0.3`, then `<0.4`) was useful when the package was new and we
# hadn't built up a track record yet. Several releases in (clean
# semver discipline, explicit breaking-change callouts on every
# release), the cost-benefit has tipped. `<1.0` accepts every 0.x
# release while still guarding against a future v1.0 that might ship
# real breaking changes.
bsky-saves>=0.2.2,<1.0
